01 — Verdict

The site had one crawlable URL and no crawlable text

Two independent faults were compounding. Every route except the homepage returned a hard 404 in production, and the homepage itself shipped an empty <div id="root"> — so the one URL that did resolve contained no readable content for any crawler that does not execute JavaScript. That describes most AI answer engines. Both are fixed.

What this cost, in plain terms

The /services page — carrying eight FAQs and valid FAQPage schema — and the entire /contact lead-capture page were never indexable. The sitemap actively submitted both URLs to Google, and both returned 404. Any shared link, ad click, or direct visit hit an error page.

03 — Remediation

What was built

Static prerendering

A Node render pass now writes a complete HTML document for every route at build time. React 19 hoists document metadata to the front of the render stream rather than exposing it through a Helmet context, so the prerenderer relocates those tags into <head> and marks them; the client drops the marked copies immediately before hydration, leaving exactly one of each. The build fails loudly if any route renders empty or without a title — a silently client-only build cannot ship again.

Blog system with schema derived from visible content

Posts are Markdown with frontmatter. FAQPage schema is extracted from each post's visible FAQ section rather than declared separately, which makes it structurally impossible for the markup to describe content a reader cannot see. Sitemap and llms.txt regenerate from the content directory on every build.

Entity graph

Regina now exists as a first-class Person with a stable @id, license credential, knowsAbout topics, and languages — referenced as author on every article and as employee of the agency entity. Per-page BreadcrumbList and BlogPosting schema replace the single malformed site-wide breadcrumb.

08 — Blocked

What needs the client

  • Profile URLs for sameAs — Google Business Profile, Zillow, Realtor.com, Facebook, Instagram, LinkedIn, Yelp. Highest-value remaining task; cannot be invented, since fabricated URLs would actively damage entity resolution.
  • A decision on review counts. Either surface the 17 individual reviews the schema claims, or change the markup to reflect what is genuinely verifiable and displayed.
  • Confirm the deployed route behaviour after the first deploy. Vercel serves /blog/slug from the prerendered directory index; this is standard static hosting behaviour but is the one thing not verifiable from local build output.
  • Google Search Console access to submit the sitemap and monitor indexing.
